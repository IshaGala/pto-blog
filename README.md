# PTO Blog

A full-stack blog application built using React, Node.js, and Express. The application allows users to view blog posts, search for content, and submit newsletter subscriptions.

## 🌐 Live Demo

**Frontend (Vercel):**
https://pto-blog.vercel.app/

**Backend API (Render):**
https://pto-blog-api-y5jk.onrender.com/

---

## ✨ Features

* 📖 View blog posts
* 🔍 Search blog posts
* 📰 Newsletter subscription form
* ⚡ Fast and responsive user interface
* 🔗 React frontend connected with Express REST API
* 📦 JSON-based data storage
* 🚀 Deployed frontend and backend

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/IshaGala/pto-blog.git

cd pto-blog
```

---

# Backend Setup

Navigate to the server folder:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

Backend will run locally at:

```
http://localhost:5000
```

---

# Frontend Setup

Open another terminal and navigate to the client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm run dev
```

Frontend will run locally at:

```
http://localhost:5173
```
